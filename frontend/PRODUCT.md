# Product

## Register

product

## Users

เจ้าหน้าที่ฝ่ายทรัพยากรบุคคล (HR) เป็นผู้ใช้งานหลักและผู้ใช้งานเพียงกลุ่มเดียว ใช้ระบบบนเดสก์ท็อปเพื่อดูแลข้อมูลพนักงานและแผนกในงานประจำวัน ต้องค้นหา เพิ่ม แก้ไข และตรวจสอบข้อมูลได้อย่างรวดเร็วโดยไม่ต้องเรียนรู้ระบบที่ซับซ้อน

## Product Purpose

ระบบนี้รวมการจัดการพนักงานและแผนกไว้ในที่เดียว เพื่อให้ข้อมูลบุคลากรเป็นระเบียบ ค้นหาได้ง่าย และลดความผิดพลาดจากการกรอกข้อมูล ความสำเร็จคือเจ้าหน้าที่ HR สามารถทำ CRUD หลักได้ครบ เข้าใจสถานะของข้อมูลได้ทันที และทำงานจบโดยไม่ติดขัดหรือสงสัยว่าต้องทำอะไรต่อ

## Brand Personality

เรียบง่าย มืออาชีพ สะอาด น้ำเสียงตรงไปตรงมา สุภาพ และช่วยให้ผู้ใช้มั่นใจว่าข้อมูลสำคัญได้รับการจัดการอย่างเป็นระบบ

## Anti-references

- หน้าจอแอดมินที่อัดแน่นด้วยเมนู กราฟ หรือข้อมูลที่ไม่เกี่ยวกับงานหลัก
- UI ที่ตกแต่งมากเกินไป ใช้ gradient, glassmorphism หรือ animation เพื่อความสวยงามโดยไม่มีหน้าที่
- ฟอร์มที่แบ่งหลายขั้นตอนโดยไม่จำเป็น หรือซ่อนข้อมูลสำคัญไว้หลัง interaction ที่คาดเดายาก
- งานตัวอย่างที่ดูสวยเพียงผิวเผินแต่ขาด validation, loading, empty, error และ responsive states

## Design Principles

1. งานหลักต้องอยู่ใกล้มือ — การค้นหา เพิ่ม และแก้ไขข้อมูลควรมองเห็นและเข้าถึงได้ทันที
2. ความชัดเจนมาก่อนการตกแต่ง — ใช้ลำดับชั้น ข้อความ และสถานะที่อ่านแล้วเข้าใจได้โดยไม่ต้องเดา
3. ป้องกันข้อผิดพลาดตั้งแต่ต้น — ฟอร์มต้องให้ข้อจำกัดและ feedback ที่เหมาะสมทั้งก่อนและหลังส่งข้อมูล
4. รายละเอียดต้องครบ — ทุกหน้าต้องรองรับ loading, empty, error, disabled และ responsive states อย่างสมเหตุสมผล
5. ความสม่ำเสมอสร้างความน่าเชื่อถือ — controls, spacing, สีสถานะ และคำเรียกต้องใช้ภาษาเดียวกันทั้งระบบ

## Accessibility & Inclusion

ไม่กำหนด certification เฉพาะ แต่ต้องรักษาพื้นฐานที่ดี: semantic controls, keyboard focus ที่มองเห็นได้, contrast อ่านง่าย, label ครบถ้วน และไม่สื่อความหมายด้วยสีเพียงอย่างเดียว Motion ใช้เฉพาะเพื่ออธิบาย state change หรือ feedback ระยะสั้น และรองรับ `prefers-reduced-motion`
